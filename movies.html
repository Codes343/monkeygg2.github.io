📂 How to Add Your Movies

1
Upload your movie file to your GitHub repo inside a folder called movies/
your-repo/
├── games/
├── movies/
│   ├── inception.mp4
│   ├── interstellar.mp4
│   └── poster-inception.jpg
├── index.html
└── ...
2
Come back to this page and fill in the form below.
For File Path enter exactly: movies/yourfilename.mp4
For Poster enter the image path or any image URL from the internet (like a Google Images link).
3
Click Add Movie. It saves to your browser and appears in your library instantly. Note: GitHub has a 100MB file limit per file. For bigger movies use Git LFS or split the file.
4
To find poster images: Google the movie name → Images → right-click any image → Copy image address → paste in the Poster field.
