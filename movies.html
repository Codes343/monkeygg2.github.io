📂 How to Add Movies (Owner Only)

▶ YouTube
☁ Google Drive
📁 Direct File
1
Find the movie on YouTube. Copy the URL from the address bar, e.g. https://www.youtube.com/watch?v=dQw4w9WgXcQ
2
Open movies.html in your GitHub repo (pencil icon to edit). Find the MOVIES array and add an entry with type:'youtube' and the video ID (the part after v=):

{title:'Movie Name', type:'youtube', id:'dQw4w9WgXcQ', year:'2024', genre:'Action', poster:'https://img.youtube.com/vi/dQw4w9WgXcQ/hqdefault.jpg'}

The poster URL works automatically — just replace the ID in it.
3
Commit the change. Everyone sees it instantly.
1
Upload your movie to Google Drive. Right-click it → Share → change to Anyone with the link → copy the link.
The link looks like: https://drive.google.com/file/d/FILE_ID_HERE/view
2
Add to the MOVIES array with type:'gdrive' and just the file ID:

{title:'Movie Name', type:'gdrive', id:'FILE_ID_HERE', year:'2024', genre:'Action', poster:''}
3
For the poster, paste any image URL. Google Images → right-click image → Copy image address.
1
Upload your .mp4 file to a movies/ folder in your GitHub repo. Files must be under 25MB for web upload, or use Git LFS for larger files.
2
Add to the MOVIES array with type:'mp4':

{title:'Movie Name', type:'mp4', id:'movies/yourfile.mp4', year:'2024', genre:'Action', poster:'movies/poster.jpg'}
