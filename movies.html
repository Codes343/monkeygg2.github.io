📂 How to Add Movies (You Only)

1
In your GitHub repo, create a folder called movies/ and upload your movie files there. GitHub supports up to 100MB per file. For bigger files use Git LFS.
your-repo/
├── games/
├── movies/
│  ├── inception.mp4
│  ├── interstellar.mp4
│  └── poster-inception.jpg
├── movies.html  ← edit this file
└── index.html
2
Open movies.html in your GitHub repo (click the file, then the pencil ✏️ icon to edit). Find the MOVIES array near the bottom of the <script> tag and add your movie like this:

{title:'Inception', path:'movies/inception.mp4', year:'2010', genre:'Sci-Fi', poster:'movies/poster-inception.jpg'}

For the poster you can use a path to an image in your repo, or paste any image URL from Google Images (right-click an image → Copy image address).
3
Commit the change. Everyone who visits your site will see the movie immediately. The video plays directly in the browser — no external site needed.
