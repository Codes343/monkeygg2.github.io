BOOKMARKLETS

One-click tools you can run on any website from your browser

📖 How to Use a Bookmarklet

1
Drag the orange button to your browser's bookmarks bar. If you don't see the bar, press Ctrl+Shift+B (Windows) or Cmd+Shift+B (Mac).
2
Go to the website you want to use the tool on (e.g. go to Polytrack, then click the bookmarklet).
3
Click the bookmarklet in your bookmarks bar. The tool pops up on that page instantly.
4
On mobile: you can't drag — instead copy the code, create a new bookmark manually, then replace the URL with the copied code.

🛠️ How to Make Your Own Bookmarklet

1
Write your JavaScript code normally. Wrap it in (function(){ YOUR CODE HERE })() so it runs immediately.
2
Put javascript: at the very start — no space. This tells the browser it's code not a URL.
3
Create a new bookmark in your browser, name it anything, and paste the whole javascript:... string as the URL.
4
Click it on any page to run it. It has full access to that page's DOM, localStorage, and JavaScript environment.
