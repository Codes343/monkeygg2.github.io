📎 Bookmarklets
How to add a bookmarklet on mobile
STEP BY STEP — MOBILE
1
Copy the bookmarklet code using the Copy button below.
2
Open any webpage in your browser (e.g. google.com). Tap the Share button then tap Add Bookmark. Save it — name it anything like "PT Save".
3
Now find that bookmark. In Safari: tap the book icon → Bookmarks → find it → tap and hold → Edit. In Chrome: tap the 3 dots → Bookmarks → find it → tap and hold → Edit bookmark.
4
Clear the URL field completely then paste the copied bookmarklet code into it. Save.
5
Go to the site you want to use it on (e.g. PolyTrack). Open your bookmarks, find it, and tap it. The tool appears on the page.
